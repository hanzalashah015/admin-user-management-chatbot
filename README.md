# Admin User Management Chatbot

An admin user-management chatbot built using Python, Streamlit, SQLite, and Groq.

## Features

- Admin login
- Add users
- Delete users
- Update users
- Natural-language commands
- SQLite database
- Groq API integration
- Automatic name generation from email
- Fast local command processing

## Technologies

- Python
- Streamlit
- SQLite
- Pandas
- Groq API
